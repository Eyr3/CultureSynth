This repository contains the dataset for the paper ["CultureSynth: A Hierarchical Taxonomy-Guided and Retrieval-Augmented Framework for Cultural Question-Answer Synthesis"](https://arxiv.org/abs/2509.10886). Accepted as a Findings paper at EMNLP 2025.

## Data Files

- `topic_standard_7lang.xlsx`: The complete table of cultural topics and keywords across 7 languages
- `QA_7lang_topics_annotated_v1224.xlsx`: A part of the CultureSynth-7 dataset, containing question-answer pairs where each entry features clear and well-defined questions, culturally relevant questions, and high-quality answers.


Note: To view the table content, please download the file to avoid text display issues.
